Activity → Health no longer shows the hourly Connection check as failing on every install; the check worked, but the job crashed while saving its one-line result. The dashboard's Recently added panel now shows your newest series instead of "No series yet", and Most wanted no longer says "Every series is complete" on an empty library or when only paused series have gaps. Settings and Settings → About now show where this install keeps its config file, data folder and Python version, instead of /config/config.ini on every install. On the Releases page, Review releases no longer appears on a release whose issue isn't in your library yet, where it did nothing. The sign-in screen shows this server's address instead of the placeholder "HOME.LAN", and the first-run setup screen loads its theme and logo again. Release notes in Settings → About and What's new show bold text and code as formatting instead of raw asterisks and backticks.
