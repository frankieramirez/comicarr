A fresh install now shows a "Finish setting up" checklist in Needs you on the dashboard. It lists the four steps to a first download: library folder, ComicVine API key, indexer, and download client. Each step shows whether it's done, and if not, gives one button that opens the right setting. The checklist goes away once you've added a series and every step is done. The "Start fresh" welcome screen lists the same four steps instead of saying none are required. You can now choose the library folder in Settings, General, instead of editing config.ini, and Comicarr refuses a folder that doesn't exist on the server.
