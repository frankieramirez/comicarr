Import Inbox can now place files independently of the download file operation. Settings → Media Management has a new Import file operation control (copy, move, hardlink, or softlink). Existing installs keep following the post-processing setting until you change it, so torrent users can keep downloads on copy for seeding and set imports to move. The setting covers Import Inbox only. The "Move files on import" checkbox is now called "Place imported files in the library", because it decides whether files go to the series folder, not how they get there.
