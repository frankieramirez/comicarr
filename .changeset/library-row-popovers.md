See how a manga series is held without opening it. Point at a manga's Have count in the Library list (or tap it) and a small panel shows how many volumes you have, how many chapters sit inside those volumes and how many are separate chapter files, with the same coverage bar as the series page. Pointing at any series title shows a preview with the cover, publisher, year, status, description and latest release date.
