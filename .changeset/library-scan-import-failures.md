Library Scan import for comics now reports a series that could not be added (for example when ComicVine is unreachable) as a failure and keeps the scan results so you can retry, instead of counting it as imported. The refresh buttons on Wanted, My Releases, and Settings → Acquisition Health now spin and disable while a refresh is running. The copy button in the update guidance returns to its normal state after a few seconds, and the sidebar search, sort menu, API key field, and current-page link are now announced by screen readers.
