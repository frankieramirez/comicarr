Downloaded manga chapters get imported again. Manga series saved their name in a different format from comics, so the folder check never matched a finished chapter to its series, and every manga download sat in your downloads folder as Snatched. New chapters added by the MangaDex check were also missing the number the folder check matches on. Both are fixed. Chapters already waiting are picked up on the next folder check. If a recently added chapter still is not, refresh its series once.
