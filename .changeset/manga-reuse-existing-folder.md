Adding a manga series no longer creates a second, empty folder next to the one you already have. If your manga library has a folder named just for the title, such as "One Piece", Comicarr now uses it instead of creating "One Piece (1997)" beside it. If the formatted folder already exists, it is still used. To merge folders that were already doubled, change the series folder from its page and choose to move the files.
