AI agents connected over MCP can now make changes, once you allow it. Set `mcp_write_enabled = True` in the `[MCP]` section of `config.ini` and agents can mark an issue or annual Wanted or Skipped, and pause or resume automatic searching for a series. While it is off, agents don't see these tools at all. Every change an agent makes shows in Activity with "via MCP" beside it.
