Library and import folders are now set in one place: Settings, Folders and naming. The library folder, manga library folder, comic and manga folders to scan, and the import folder can all be changed there; each must be a full path to a folder that exists, and the import folder cannot sit inside, or contain, a library or download folder. Import now scans the library folder when no separate comic folder is set, so the dashboard and Import agree on where your comics are. Manga scans fall back to the manga library folder only, never the comic one.
