Prowlarr can now sync its Usenet and torrent indexers into Comicarr. In Prowlarr, add Comicarr under Settings → Apps as a **Mylar** application with Comicarr's URL and API key (Settings → API). Prowlarr adds, updates and removes its indexers in Settings → Search as Newznab and Torznab entries named "… (Prowlarr)" with the Comics categories, and turns on Newznab or Torznab search if it was off (torrent indexers still need torrent search and a torrent client). Indexers you added yourself are left alone.
