qBittorrent can now send torrents for Series in a chosen library root to their own category and save path. For example, magazines under `/comics/Magazines` can download to a `magazines` category in `/downloads/Magazines`. Set this up under Settings → Download Clients → qBittorrent categories by library root, with one `library root | category | save path` line per root. Series outside those roots keep the global qBittorrent category and folder.
