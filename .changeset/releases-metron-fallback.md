Releases fills the week from Metron when Walksoftly is down and a Metron login is set in Settings. ComicVine stays the last fallback, since it often lists almost nothing for the current week. When no source has the week, Releases now says why for each source (unreachable, not set up, or nothing listed yet) instead of only saying the list is empty.
