Setup is easier to get right. Add a series shows a visible Search button, and warns next to the search box when comic search has no Comic Vine API key, with a link to add one. The completed downloads folder the Folder Monitor watches can now be set in Settings → Download clients instead of only in config.ini. Indexers and Prowlarr are at the top of Indexers and search, above the pacing and quality settings. When the Mylar3 import can't find the folder you entered, it names that path, says whether it looked inside the Docker container, and links to the volume example.
