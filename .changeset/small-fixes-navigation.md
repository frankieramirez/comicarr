Several small fixes from an outside walkthrough. Clicking a Settings section right after the page loads always opens it now. The log level picker shows its name (Info, Debug) instead of a number. A mistyped or old link shows a "This page doesn't exist" page with the address you tried, instead of quietly opening the dashboard. Reloading Search on Manga stays on Manga. Library filters ignore spaces at the ends of what you type. The Blackhole folder and Watch folder download clients can be set up in Settings → Download clients. The SABnzbd Test button works right after saving, without a reload. A failed settings save shows one error, not two. A missing series shows a friendly not-found page, and the Releases page no longer names an internal data source when the release calendar is down.
