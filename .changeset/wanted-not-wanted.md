"Wanted" now means the same thing everywhere. Before, the dashboard counted every gap as wanted, the series page counted Skipped issues as missing, and only the Wanted page counted what Comicarr would actually search for. Now the series page splits gaps into Wanted and Not wanted chips, the progress bar and "Search N wanted" button count only wanted issues, and the dashboard's Most wanted ranks series by the same count as the Wanted page. A not-wanted issue has a Want button on its row. Issues marked Skipped or Ignored, including ones carried over from Mylar, are no longer picked up by "Search missing" or automatic search; mark them Wanted to search for them again.
