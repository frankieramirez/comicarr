# Triage labels

Canonical role on the left, the label string on this tracker on the right. The skills read the right column.

| Role | Label |
|------|-------|
| bug | bug |
| enhancement | enhancement |
| needs-triage | needs-triage |
| needs-info | needs-info |
| ready-for-agent | ready-for-agent |
| ready-for-human | ready-for-human |
| wontfix | wontfix |

A triaged ticket carries exactly one category (bug or enhancement) and one state.
